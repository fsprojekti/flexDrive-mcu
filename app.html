🔧 FlexDrive – Web Serial vmesnik

Poveži se z ESP32, pošiljaj CLI ukaze (mode, run, ref, kp …) in spremljaj odziv sistema. Deluje v brskalnikih s podporo za Web Serial API (npr. Chrome, Edge).
🔌 Povezava
● Disconnected
Če gumb ne deluje, uporabite Chrome/Edge in omogočite HTTPS (če je mogoče).
🎛️ Način in pogon
Open (0)
Closed (1)
⚙️ Reference & PID
📈 Čas vzorčenja & plot
Za nalogo τ uporabite tipično: ts 10, plot_period 5, plotSerialClosed.
⌨️ Ročni ukaz
📝 Serijski log
read-only
📈 Plot – hitrost (vel)
experimental
Plot poskuša iz plotSerialClosed vrstic obdelati vel:<številka> in izrisati hitrost. Arduino Serial Plotter je še vedno uradno priporočeno orodje.
ℹ️ Napravo vedno najprej konfigurirajte s CLI ukazi (mode, ref, kp...) in šele nato analizirajte odziv.
